YouTube API Key

API key kaise banayen? (muft, 2 minute)
  1. Google Cloud Console par apne Google account se jayein.
  2. Upar se ek naya project banayein (ya koi bhi select kar lein) — "YouTube Data API v3" search karke usay Enable karein.
  3. Left menu se Credentials → Create Credentials → API Key par click karein.
  4. Jo key milay wo copy karke upar wale box mein paste kar dein aur Save dabayein.

Ye key sirf aapke is browser mein save hoti hai — kahin aur nahi jati. Muft quota rozana kaafi videos list karne ke liye kaafi hai.
